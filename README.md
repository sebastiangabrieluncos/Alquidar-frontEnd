# Alquidar

##  Descripción

Alquidar es un sistema web de gestión de alquileres que busca centralizar y organizar la información relacionada con propiedades, propietarios, inquilinos, contratos, pagos y vencimientos.

El proyecto surge con el objetivo de facilitar la gestión de los alquileres y mejorar el seguimiento de la información entre propietarios e inquilinos.

##  Variables CSS

Las variables CSS se definirán utilizando `:root` y se reutilizarán mediante `var()`.

Se utilizarán principalmente para centralizar:

* Colores.
* Espaciados.
* Bordes.
* Sombras.

Esto permite mantener una identidad visual coherente y facilita la modificación de los estilos del proyecto.


##  Responsive Design

El proyecto deberá adaptarse correctamente a diferentes tamaños de pantalla:

*  Celulares.
*  Tablets.
*  Computadoras.



##  Estrategias SEO

Como parte del proyecto se implementarán diferentes estrategias de SEO.

Entre ellas:

1. Uso de un `<title>` descriptivo.
2. Implementación de `meta description`.
3. Utilización de HTML semántico.
4. Uso de atributos `alt` descriptivos en imágenes.
5. Implementación de enlaces internos descriptivos.

También se trabajará en una correcta jerarquía de encabezados mediante `h1`, `h2` y `h3`.
